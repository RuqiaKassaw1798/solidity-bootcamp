# SimpleStorage Contract

This is the first project of the Solidity Bootcamp. 

## What the contract does:
- Stores a `uint256` number on the blockchain.
- Allows users to update the number.
- Allows users to retrieve the stored number.
- Includes a bonus function to increment the number by 1.

## Functions:
1. `store(uint256 _favoriteNumber)`: Updates the state variable.
2. `retrieve()`: Returns the current value of the stored number.
3. `increment()`: Increases the stored number by 1.
